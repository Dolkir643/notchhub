# Сборка и установка обновления

Workflow **Build and test** собирает приложение на macOS после отправки
изменений в GitHub и для pull request.
Если workflow уже есть в основной ветке, его также можно запустить кнопкой
**Run workflow** на вкладке **Actions**, выбрав нужную ветку.

Перед упаковкой выполняются `swift test`, сборка с минимальной целевой
версией macOS 11 и проверки сторожа сна с подменёнными системными командами.
Затем проверяются обе
архитектуры приложения и MediaRemoteAdapter, минимальная версия macOS
и ad-hoc подпись приложения внутри DMG.

## Скачать и установить

1. На GitHub открой **Actions → Build and test** и успешный запуск
   с нужным коммитом. Внизу страницы, в **Artifacts**, скачай
   `NotchHub-<коммит>`. В архиве есть три варианта образа:

   | Образ | Система и поведение |
   |---|---|
   | `NotchHub-<версия>-no-notch.dmg` | macOS 14+, открытие индикатора кликом на экранах без выреза |
   | `NotchHub-<версия>-notch.dmg` | macOS 14+, раскрытие наведением |
   | `NotchHub-<версия>-macOS11.dmg` | macOS 11–13 |

   Все варианты универсальные: Intel и Apple Silicon. Для загрузки артефактов
   Actions нужен вход в GitHub. Срок хранения — 30 дней после сборки.

2. Распакуй скачанный архив и выбери подходящий DMG. Рядом есть дополнительные
   архивы приложений `.app.zip`, контрольные суммы и `COMMIT.txt` с точной
   версией исходников.
3. В старом NotchHub выключи «Не засыпать», если этот режим уже доступен,
   дождись восстановления сна и выйди из приложения через его настройки.
   Дождись полного завершения: если после «Выйти» панель остаётся или
   открылась с ошибкой, приложение пока не заменяй.
4. Открой DMG и перетащи NotchHub в «Программы», подтвердив замену.
   Устанавливается один вариант; существующие настройки, полка и заготовки
   хранятся отдельно и сохраняются при замене приложения.
5. Первый запуск: правый клик по `/Applications/NotchHub.app` → **Открыть**.
   Если macOS блокирует запуск, открой системные настройки
   **Конфиденциальность и безопасность → Всё равно открыть**.
   Приложение подписано ad-hoc и не нотаризовано.

Если DMG использовать неудобно, распакуй `.app.zip` и так же перенеси
`NotchHub.app` в «Программы». Не запускай обе копии одновременно.

В обновлённом приложении проверь **Полка → Загрузки** и
**Настройки → Не засыпать**. Автоматические проверки не подтверждают
работу закрытой крышки на конкретном Mac: эту функцию нужно проверить
на самом устройстве, включая выключение режима и восстановление сна.

## Собрать на своём Mac

Нужны полный Xcode 16 или новее со Swift 6 и CMake. `Scripts/build.sh`
принимает выбранный Xcode через `DEVELOPER_DIR`.

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
python3 Tests/KeepAwakeWatchdogTests.py
swift test
NOTCHHUB_VARIANT=no-notch ./Scripts/dmg.sh
./Scripts/verify-dmg.sh build/NotchHub-*-no-notch.dmg no-notch
```

Для macOS 11–13 выполни `MACOS11=1 swift build --scratch-path .build-legacy`, затем
`NOTCHHUB_VARIANT=legacy ./Scripts/dmg.sh`. Вариант с чёлкой собирается
с `NOTCHHUB_VARIANT=notch`. Сборка для старой системы на новом Mac
проверяет совместимость API при компиляции; запуск на macOS 11–13
проверяется отдельно на соответствующей системе.

Workflow сохраняет проверенные файлы в артефактах Actions. Публикацию
GitHub Release и установку на личный Mac он не выполняет.
